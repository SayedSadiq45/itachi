## The Experience

AURA is an immersive personal portfolio for **Sayed Sadiq**, shaped around movement, atmosphere, and focus. It combines cinematic image sequences with interaction-led motion to turn a portfolio visit into a memorable visual journey.

The experience moves through three signals:

- **Awakening** — scroll through a frame-by-frame visual sequence.
- **Focus** — move your cursor and watch the eyes track your presence.
- **Aura** — reveal an atmospheric WebGL field and explore the final links.

## Built Into The Page

| Detail | What it does |
| --- | --- |
| Scroll-scrubbed frames | 71 main frames create a cinematic opening sequence. |
| Mouse-tracked eyes | 51 eye frames respond to pointer movement. |
| WebGL ghost cursor | A reactive red energy field follows interaction. |
| Ambient atmosphere | Grain, storm flashes, lightning, embers, and sound controls build depth. |
| Responsive layout | The composition adapts for touch, desktop, and reduced-motion preferences. |

## Run It Locally

This is a lightweight static site. Serve the project directory with any local web server so the frame assets load correctly.

```bash
git clone https://github.com/SayedSadiq45/itachi.git
cd itachi
```

Then open it with a static server, for example:

```bash
npx serve .
```

Open the local URL shown in your terminal.
